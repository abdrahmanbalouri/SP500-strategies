# SP500 strategies

Machine learning strategy that uses a signal generated by a Random Forest to try
to outperform the S&P 500.

## Data

- `data/all_stocks_5yr.csv` - OHLCV of the S&P 500 constituents.
- `data/HistoricalPrices.csv` - OHLC of the S&P 500 index (benchmark).
- `data/sp500.csv` - generated by `features_engineering.py`.

## Pipeline

1. `features_engineering.py` - builds the leakage-free dataset (features + target).
2. `gridsearch.py` - cross-validation, grid search, ML metrics and feature importance.
3. `model_selection.py` - fits the selected pipeline on the whole train set.
4. `create_signal.py` - generates the machine-learning signal.
5. `strategy.py` - backtests the signal and writes the report.

## Run

```bash
python scripts/features_engineering.py
python scripts/gridsearch.py
python scripts/model_selection.py
python scripts/create_signal.py
python scripts/strategy.py
```
